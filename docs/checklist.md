# Landing page launch checklist

## Message
- [ ] Headline states the outcome, not the feature
- [ ] Subheadline says who it is for
- [ ] One primary CTA, repeated at the end

## Proof
- [ ] Logos, numbers or testimonials above the fold or right after it
- [ ] Each claim is specific and checkable

## Technical
- [ ] Page loads in under 2.5s on mobile (LCP)
- [ ] Title and meta description set
- [ ] All `{{placeholders}}` filled (run `fill-template.js`; it lists any left)
- [ ] Form submits and shows a confirmation
- [ ] Analytics and conversion event firing
